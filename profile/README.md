# QuantifiedESG

퀀티파이드이에스지는 ESG 보고, 실사, 탄소 중립을 위한 맞춤형 ESG 서비스 솔루션을 제공하여 지속 가능한 가치를 창출합니다.

- 홈페이지: <https://qesg.co.kr/>
- 문의: <info@qesg.co.kr>

## QESG Core

ESG 공시 업무를 하나의 플랫폼에서. 데이터 수집부터 온실가스 산정, 기후·자연 리스크 분석, 보고서 발간까지 하나의 계정과 AI 에이전트로 연결합니다.

| 앱 | 소개 |
|---|---|
| **ERT** (ESG Reporting Tool) | 보고서 작성, 웹·PDF 발간, 영문 번역 |
| **DMS** | ESG 데이터 수집, 검증, 승인 |
| **GHG** | Scope 1·2·3 산정, 협력사 배출량 수집 |
| **Climate-Risk** | 물리적·전환 리스크, 시나리오 분석 |
| **TNFD** | 자연 의존도·영향 평가, LEAP 접근법 |
| **Assessment** | 공급망 리스크 진단·평가, 실사 기반 리스크 관리 |

## 인증과 파트너십
