# QuantifiedESG

퀀티파이드이에스지는 ESG 보고, 실사, 탄소 중립을 위한 맞춤형 ESG 서비스 솔루션을 제공하여 지속 가능한 가치를 창출합니다.

- 홈페이지: <https://qesg.co.kr/>
- QESG Core 소개: <https://quantified-esg-inc.github.io/qesg-core-intro/>
- 문의: <info@qesg.co.kr>

## 서비스

| 서비스 | 소개 |
|---|---|
| **ESG Reporting Tool** | 비재무 데이터 공개 요구에 따른 효율적 공시 솔루션입니다. 글로벌 공시 가이드라인(GRI, SASB, TCFD, KSSB 및 ISSB)에 맞춰 보고서를 발간합니다. |
| **Data Management System** | 엑셀 호환 및 자동 검증 로직을 통해 글로벌 조직의 데이터를 무결하게 수집합니다. 히스토리 기반 정확도 높은 관리로 데이터 활용성을 높입니다. |
| **Assessment** | 공급망 리스크를 진단하고 평가합니다. 평가 및 실사에 기반한 리스크 관리 파이프라인을 구축합니다. |
| **Carbon** | Scope 1·2·3 배출량을 정밀하게 산정하고 감축 시나리오를 시뮬레이션합니다. 데이터 취합부터 사업장별 피드백, 결과 보고서 제공 및 감축 목표 수립 지원 등의 서비스를 제공합니다. |

## QESG Core

ESG 공시 업무를 하나의 플랫폼에서. 데이터 수집부터 온실가스 산정, 기후·자연 리스크 분석, 보고서 발간까지 하나의 계정과 AI 에이전트로 연결합니다.

| 앱 | 소개 |
|---|---|
| **ERT** (ESG Reporting Tool) | 보고서 작성, 웹·PDF 발간, 영문 번역 |
| **DMS** | ESG 데이터 수집, 검증, 승인 |
| **GHG** | Scope 1·2·3 산정, 협력사 배출량 수집 |
| **Climate-Risk** | 물리적·전환 리스크, 시나리오 분석 |
| **TNFD** | 자연 의존도·영향 평가, LEAP 접근법 |

## 인증과 파트너십

- ISO/IEC 27001 인증
- IFRS SASB Level 3 · ISSB Standard 라이선스
- GRI 소프트웨어 인증
- AA1000 라이선스 파트너
