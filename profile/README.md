# QuantifiedESG

퀀티파이드이에스지는 ESG 보고, 실사, 탄소 중립을 위한 맞춤형 ESG 서비스 솔루션을 제공하여 지속 가능한 가치를 창출합니다.

## 서비스

| 서비스 | 소개 |
|---|---|
| **ESG Reporting Tool** | 통합 ESG 정보공시 솔루션. 데이터 수집부터 글로벌 표준에 맞춘 보고서 발간까지 지원합니다. |
| **QESG Assessment** | 지속가능한 공급망과 투자를 위한 제3자 협력사 ESG 조사·평가 서비스입니다. |
| **Data Management System** | 흩어진 ESG 데이터를 통합 관리하도록 데이터 수집부터 검증까지 지원합니다. |
| **Carbon Platform** | 협력사의 온실가스 배출량 데이터를 통합 수집·관리합니다. |
